# Support

Nightjar is pre-v1. The current `main` branch is unreleased, and there are no
official releases or supported platforms yet. When official releases exist,
support covers only the named releases and the platforms listed with them.

Use GitHub Issues for a bug report or a question. We help where we can, and
there is no response-time commitment. Report a security issue through the
private route in [SECURITY.md](SECURITY.md), never a public issue.

## Forks and modified builds

A fork or a modified build is unofficial. We do not support it, and a problem in
it is not a Nightjar bug. This does not forbid forks or modifications: the
GPL-3.0-only licence grants those rights. It means only that official support
follows official origin.
