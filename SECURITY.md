# Security policy

Report a security vulnerability through GitHub private vulnerability reporting,
which is enabled for this repository:

<https://github.com/nightjar-tv/nightjar/security/advisories/new>

Do not open a public issue for a vulnerability. Use GitHub Issues for ordinary
bugs and questions, and the private route above for anything security-related.

## What to include

- **Impact.** What an attacker can do, and what they need to start.
- **Reproduction.** The smallest steps, request or file that shows the issue.
- **Version.** The release tag or commit you tested.

Redact secrets, tokens and personal data before you attach a log or a file. If
a proof of concept needs media, use a small synthetic sample or one you have the
right to share.

## What to expect

Nightjar is pre-v1. The current `main` branch is unreleased, so there is no
supported-version claim and no response-time commitment. We follow up in the
private advisory thread.
